# Python Learning Lab

A public learning workspace by **Dhananjaya Vijebahu**, a Production Manager exploring Python, industrial data analytics, and manufacturing dashboards.

## Learning roadmap

1. **Python foundations:** variables, collections, conditions, loops, and functions.
2. **Working with data:** read sample CSV files, handle missing values, and validate inputs.
3. **Analysis:** summarize synthetic production records and calculate clearly defined indicators.
4. **Visualization:** build readable charts with labels, units, and explanatory notes.
5. **Small projects:** combine these skills in focused, reproducible demonstrations.

## Suggested organization

- `basics/` — foundational exercises.
- `data-analysis/` — small analysis examples.
- `visualization/` — charts and explanations.
- `mini-projects/` — self-contained learning projects.
- `data/sample/` — synthetic or openly licensed sample data.

These folders are a proposed structure; this repository currently contains the starter README only. Exercises and setup instructions will be added as projects develop.

## First exercise

Use a short list of fictional daily production quantities to calculate the total and average. Explain the units, assumptions, and result before adding a chart.

## Responsible sharing

Use synthetic or openly licensed public data and credit sources and licenses. Never commit confidential company data, internal documents, credentials, or personal information. All manufacturing examples are educational demonstrations, not actual plant reports or validated operational recommendations.
